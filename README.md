## 📝 Описание проекта

**WhiteNoiseRoad** — это игра с бесконечной процедурной генерацией дороги в режиме реального времени на **HDRP (High Definition Render Pipeline)** с поддержкой **Ray Tracing**. Проект демонстрирует современные техники генерации контента, кастомной физики, GPU-оптимизаций и графического реализма для игр с открытым миром.

Основные особенности:
* 🛣️ Бесконечная генерация дороги с поворотами, прямыми участками и разнообразными сегментами
* 🚗 Кастомная физика автомобиля на основе raycast-колёс с реалистичной slip-моделью шин (ВАЗ-2114, FWD)
* 🌿 Высокопроизводительная система травы с GPU Instancing, 3 уровнями LOD и патчами
* 🎥 Динамическая камера от первого лица с G-Force эффектами (наклон в поворотах, FOV от скорости)
* 🌳 Процедурная генерация окружения по бокам дороги с DistanceField
* 💡 HDRP с Ray Tracing для реалистичных отражений и освещения
* ⚡ Оптимизация: до 20,000+ инстансов травы при стабильных 60+ FPS

## 📐 Архитектура системы

Игра использует модульную архитектуру с разделением на основные компоненты:

### 🏗️ Ключевые инженерные решения

**Генерация дороги:**
* **Модульная система префабов** с точками стыковки `StartPoint` и `EndPoint` для идеального соединения сегментов
* **Автоматическая подстройка высоты земли** под асфальт через `DetectRoadHeight` (raycast/bounds detection)
* **Защита от пересечений** через DistanceField — предотвращает наезд дороги самой на себя
* **Ahead-based spawning** — дорога всегда достраивается вперёд на `aheadDistance` метров
* **Безопасное удаление** — чанки удаляются по `destroyDistance` позади игрока (поддержка движения назад)

**Физика автомобиля (кастомная, без WheelCollider):**
* **Raycast-based wheels** — 4 независимых колеса с подвеской (spring + damper)
* **Настоящая slip-модель** — longitudinal slip ratio + lateral slip для реалистичного поведения шин
* **FWD (передний привод)** — тяга прикладывается в точки контакта передних колёс
* **Ackermann steering** — внутреннее колесо поворачивается сильнее внешнего
* **Anti-roll bars** — стабилизация крена в поворотах
* **Speed-sensitive steering** — уменьшение угла руля на высокой скорости

**Система травы (GPU Instancing + LOD):**
* **Patch Grass Mesh** — 1 instance = патч из нескольких травинок (48/16/3 для LOD0/1/2)
* **3 уровня LOD** с прореживанием количества инстансов, а не только полигонажа
* **GPU Instancing** через `Graphics.DrawMeshInstanced` с батчами по 1023
* **Frustum culling** на уровне патчей (sphere vs 6 planes)
* **Кеширование матриц** — `Matrix4x4` считаются только при rebuild, не каждый кадр
* **Ветер через Custom Function** в Shader Graph с когерентной волной по всему полю

**Оптимизация ландшафта:**
* **Раздельный render/collision mesh** — render до 256×256, collision 64×64
* **Клампинг разрешения** — защита от ошибок "Source mesh has over 2,097,152 triangles"
* **DistanceField** для быстрого определения расстояния до препятствий

**HDRP + Ray Tracing:**
* **RTAS-совместимые меши** — конвертация Quads в Triangles через Editor-скрипт
* **Реалистичные отражения** на асфальте и кузове машины
* **Unlit Shader Graph** для травы с Alpha Clipping и GPU Instancing

## 🌟 Основные возможности

### 🚗 Управление и физика

**Кастомная физика автомобиля (без WheelCollider):**
* **Raycast-based подвеска** — spring + damper для каждого колеса
* **Настоящая slip-модель шин** — longitudinal slip ratio + lateral slip
* **FWD (передний привод)** — тяга в точках контакта передних колёс
* **Ackermann steering** — правильная геометрия поворота колёс
* **Anti-roll bars** — стабилизация крена (front: 9000 N, rear: 7000 N)
* **Speed-sensitive steering** — угол руля уменьшается с ростом скорости
* **Ручник (Space)** — контролируемый занос задней оси
* **Перенос веса** — динамическое изменение нагрузки на колёса

**Характеристики ВАЗ-2114:**
* Масса: 1050 кг
* Максимальная тяга: 8000 Н (FWD)
* Максимальная скорость: ~50 м/с (180 км/ч)
* Время разгона 0-100 км/ч: ~4-5 сек

### 🛣️ Генерация дороги

**Модульная система:**
* Сегменты дороги соединяются через точки стыковки `StartPoint` и `EndPoint`
* Автоматическое выравнивание по позиции и повороту
* Хранение копии точки стыковки (не ссылки) — безопасное удаление чанков

**Ahead-based spawning:**
* `aheadDistance` (300-400 м) — дорога всегда впереди игрока
* `destroyDistance` (1000 м) — поддержка движения назад
* Защита от исключений через try/catch + retry logic

**Автоматическая подстройка высоты:**
* `DetectRoadHeight` — определяет высоту асфальта через raycast или bounds
* Земля у дороги подстраивается под высоту полотна
* Плавный переход к холмам через `blendZone`

**DistanceField для защиты от пересечений:**
* Быстрое определение расстояния до препятствий
* Предотвращает наезд дороги самой на себя
* Используется для генерации травы (избегание дорог)

### 🌿 Система травы (GPU Instancing)

**Patch Grass Mesh:**
* 1 GPU instance = патч из нескольких травинок (не 1 травинка)
* LOD0: 48 травинок (crossed quads) — близко (0-25 м)
* LOD1: 16 травинок (single quads) — средняя дистанция (25-55 м)
* LOD2: 3 травинки (tuft) — далеко (55-100 м)

**Оптимизации:**
* GPU Instancing через `Graphics.DrawMeshInstanced` (батчи по 1023)
* Frustum culling на уровне патчей (sphere vs 6 planes)
* Кеширование `Matrix4x4` — считаются только при rebuild
* Ноль аллокаций в Update/FixedUpdate
* Детерминированный `Hash01(x, z, salt)` вместо `Random`

**Визуальное качество:**
* Ветер через Custom Function `GrassWind.hlsl`
* Когерентная волна ветра по всему полю (фаза от мировой позиции)
* Изгиб от UV.y (корень закреплён, верхушка качается)
* 2 варианта мешей на LOD для разнообразия

**Производительность:**
* ~1000-1200 инстансов (вместо 12-14 тыс. в старой системе)
* 6-10 draw calls (вместо сотен)
* Стабильные 60+ FPS при 20,000+ травинок

### 📷 Камера и визуализация

**Камера от первого лица:**
* Плавный mouse look с `SmoothDampAngle`
* G-Force эффекты:
  * Roll (наклон) от бокового скольжения и реального крена кузова
  * Pitch от ускорения/торможения
  * Yaw offset — камера отстаёт от поворотов машины
* Динамический FOV от скорости (60° → 75° на максималке)
* Многослойная тряска: низкочастотная (подвеска) + высокочастотная (двигатель)

**Управление камерой:**
* Мышь — обзор
* R — сброс камеры в центр
* Esc — разблокировка курсора

### 🌳 Окружение

**Процедурная генерация:**
* Деревья, камни, здания по бокам дороги
* DistanceField для избегания дорог
* Вероятностный спавн (`spawnProbability`)
* Выравнивание по нормали террейна (`alignToTerrain`)

**Оптимизация:**
* Удаление по дистанции от игрока
* Контейнеризация (`EnvironmentContainer`)
* Вариативность масштаба и поворота

### 💡 HDRP + Ray Tracing

**Графические возможности:**
* HDRP (High Definition Render Pipeline) для фотореалистичной графики
* Ray Tracing для отражений на асфальте и кузове
* Unlit Shader Graph для травы с Alpha Clipping
* Double-Sided рендеринг травы

**RTAS-совместимость:**
* Editor-скрипт `EmptyMeshFixer` конвертирует Quads → Triangles
* Автоматическое исправление мешей дорог для Ray Tracing
* Сохранение в префабы через `AssetDatabase.AddObjectToAsset`

## 🛠 Технологический стек

### Графика и рендеринг
* **Render Pipeline:** HDRP (High Definition Render Pipeline)
* **Ray Tracing:** DXR (DirectX Raytracing)
* **Shaders:** Shader Graph + HLSL (GrassWind.hlsl)
* **GPU Instancing:** Graphics.DrawMeshInstanced

### Физика и геймплей
* **Physics Engine:** Unity Physics (Rigidbody)
* **Custom Car Physics:** Raycast-based wheels + slip model
* **Input System:** Unity Input System (new)
* **Procedural Generation:** DistanceField + ahead-based spawning

### Оптимизации
* **GPU Instancing:** до 1023 instances per batch
* **Frustum Culling:** sphere vs 6 planes для патчей травы
* **LOD System:** 3 уровня с прореживанием инстансов
* **Matrix Caching:** кеширование Matrix4x4 между rebuilds
* **Mesh Optimization:** раздельный render (256) / collision (64) mesh

### Разработка
* **Game Engine:** Unity 6 (6000.5.3f1)
* **Scripting:** C# 12
* **Version Control:** Git
* **AI Assistance:** Kimi, Qwen, GLM, Gemini, ChatGPT, DeepSeek (архитектурные рекомендации)

## ⚙️ Требования к окружению и Запуск

### 1. Системные требования

**Минимальные:**
* **OS:** Windows 10/11 (64-bit)
* **CPU:** Intel Core i5 / AMD Ryzen 5
* **RAM:** 8 GB
* **GPU:** NVIDIA GTX 1060 / AMD RX 580 (с поддержкой DX12)
* **Storage:** 2 GB

**Рекомендуемые (для Ray Tracing):**
* **GPU:** NVIDIA RTX 2060 или выше
* **RAM:** 16 GB
* **DirectX:** 12 Ultimate

### 2. Требования к ПО

* Unity 6 (2023.3.0f1) или выше
* .NET Framework 4.8 или выше
* HDRP Package (устанавливается через Package Manager)
* Git (для клонирования репозитория)

### 3. Установка и запуск

**Шаг 1: Клонирование репозитория**
```bash
git clone https://github.com/Pashim-machine/WhiteNoiseRoad
cd WhiteNoiseRoad
```

**Шаг 2: Открытие в Unity**
1. Запустите Unity Hub
2. Нажмите "Open" → выберите папку `WhiteNoiseRoad`
3. Дождитесь импорта ассетов (5-10 минут)

**Шаг 3: Настройка HDRP (первый запуск)**
1. Откройте `Window → Package Manager`
2. Убедитесь, что установлен `High Definition RP`
3. Откройте `Edit → Project Settings → Graphics`
4. Убедитесь, что `Scriptable Render Pipeline Settings` = `HDRenderPipelineAsset`

**Шаг 4: Настройка Ray Tracing (опционально)**
1. Откройте `Assets/Settings/HDRP Asset.asset`
2. Включите галочку `Ray Tracing`
3. Запустите Editor-скрипт `Tools → Конвертировать меши дорог в треугольники (RTAS-fix)`

**Шаг 5: Запуск игры**
1. Откройте сцену `Assets/Scenes/SampleScene.unity`
2. Нажмите кнопку **Play** (треугольник вверху)

### 4. Управление

| Клавиша | Действие |
|---------|----------|
| **W** | Газ |
| **S** | Тормоз / Задний ход |
| **A/D** | Поворот влево/вправо |
| **Space** | Ручник (занос) |
| **Мышь** | Обзор камеры |
| **R** | Сброс камеры в центр |
| **Esc** | Разблокировка курсора |

## 🎮 Геймплейные особенности

**Физика автомобиля:**
* Реалистичный передний привод (FWD) с характерным understeer
* Контролируемый занос через ручник (Space)
* Перенос веса при разгоне/торможении
* Крен кузова в поворотах

**Бесконечная дорога:**
* Процедурная генерация в реальном времени
* Возможность ехать назад до 1000 метров
* Разнообразие сегментов: прямые, повороты, рампы
* Автоматическая подстройка ландшафта под дорогу

**Высокая производительность:**
* 20,000+ травинок при 60+ FPS
* Ray Tracing без просадок производительности
* Оптимизированная генерация окружения

## 🐛 Известные проблемы

* **Ray Tracing требует RTX GPU** — на GTX картах нужно отключить RT в настройках HDRP Asset
* **Первый запуск долгий** — импорт ассетов занимает 5-10 минут
* **Требует DX12** — убедитесь, что в Player Settings стоит DirectX 12
